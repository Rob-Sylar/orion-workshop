# Mission: Career Tracker

- **Date:** 2026-11-23
- **Status:** ✓ Complete
- **Asked:** Career tracker: job applications, courses and certs with % progress, skills checklist, goals with target dates, dashboard at the top.

## What was built
Four-tab tracker with a dashboard: applications (company, role, date, status), courses/certs with % sliders, a skills checklist and goals with target dates, days left and progress bars. Saved with localStorage, plus copy/restore backup.

## How to use
Add items on each tab. The dashboard at the top updates live. Data stays on the device, so use Copy backup to move it between phone and PC.

## Ideas for v2
Interview date reminders, application notes, export to CSV.
