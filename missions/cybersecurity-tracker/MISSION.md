# Mission: Cybersecurity Tracker

- **Date:** 2026-11-23
- **Status:** ✓ Complete
- **Asked:** Cybersecurity tracker: study sessions with weekly target and streak, TryHackMe and cert % bars, homelab and SOC skills checklists, dashboard on top.

## What was built
Dashboard with this week's hours, streak, target and overall progress. Tabs for study log, TryHackMe rooms/paths, certs with % sliders, a homelab task checklist and a SOC skills checklist (logs, SIEM, networking, Windows, Linux, IR and more). Saved with localStorage, plus copy/restore backup.

## How to use
Log a session after each study block. Change the weekly target on the Study log tab. Weeks run Monday to Sunday.
