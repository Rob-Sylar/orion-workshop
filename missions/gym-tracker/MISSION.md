# Mission: Gym Tracker

- **Date:** 2026-11-22
- **Status:** ✓ Complete
- **Asked:** Gym tracker: log workouts, last time's weights, progress charts.

## What was built
Log tab: date, exercise (with suggestions), sets of kg × reps, with a 'last time' reminder. History grouped by day. Progress chart of the heaviest set per session for each exercise. Backup copy and restore.

## How to use
Pick an exercise, fill in your sets, then tap Save. Copy a backup now and then, because data lives on that one device.
